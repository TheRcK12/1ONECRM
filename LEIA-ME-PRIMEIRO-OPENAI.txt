ONE CRM 1.8.0-beta.1 - ONE Intelligence / OpenAI

PARA ATUALIZAR PELO GITHUB:
1. Faça backup em Administrativo > Backups.
2. Extraia o pacote.
3. Copie os arquivos para a raiz do repositório, preservando as pastas.
4. Faça Commit to main e Push origin no GitHub Desktop.
5. Aguarde o Railway concluir o deploy.
6. Pressione Ctrl+F5 no navegador.

NO RAILWAY > VARIABLES, ADICIONE:
OPENAI_API_KEY=sk-proj-...
OPENAI_MODEL=gpt-5.6-luna
ONE_CRM_AI_ENABLED=1

NÃO coloque a chave em nenhum arquivo do GitHub.

Depois do deploy:
Administrativo > Integrações > Testar OpenAI

Permissão necessária para os cargos:
Inteligência > Utilizar o assistente ONE Intelligence com OpenAI

Leia CONFIGURAR_OPENAI_RAILWAY.md para detalhes.
